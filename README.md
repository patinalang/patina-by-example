# Patina By Example

Learn Patina with examples.

This is an implementation-guiding document, and completing it was intended to force answers to several language design questions.

This repository is a modified version of [Rust by Example (RBE)][rbe].
In most places, the modifications are surface-level only, as the intended Patina syntax and semantics closely mirror Rust.

```bash
git clone https://github.com/patina-lang/patina-by-example
cd patina-by-example
cargo install mdbook
mdbook build
mdbook serve
```

[rbe]: https://github.com/rust-lang/rust-by-example
